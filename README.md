# Payroll Analysis Dashboard (Power BI)

## Project Overview
This project focuses on analyzing weekly payroll data using Power BI.
It provides insights into employee earnings, deductions, and net pay across different cities in Ireland.

## Tools & Technologies
- Power BI
- Microsoft Excel
- Payroll dataset

## Key Dashboard Metrics
- Hourly Pay
- Gross Pay
- Overtime Pay
- Total Deductions
- Net Pay

## Deduction Breakdown
The dashboard includes a detailed breakdown of payroll deductions:
- PAYE Tax
- PRSI
- USC

## Geographical Analysis
- City-wise payroll distribution across Ireland
- Interactive map for location-based insights

## Files in This Repository
- `Payroll.pbix` – Interactive Power BI dashboard
- `Payroll.pdf` – Exported report for quick viewing
- `Payroll.xlsx` – Source payroll dataset

## Business Value
This dashboard helps HR and finance teams monitor payroll costs, understand deduction structures, and ensure accurate compensation analysis.

## Future Enhancements
- Monthly and yearly payroll trends
- Employee-level drill-down analysis
